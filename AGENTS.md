# cut-in scenario generator for autonomous driving
This is a five-person group project for course Autonomous Cyper-physical System,
focusing on control, safety, test generation/falsification

## General Requirements:
- Provide a separate "> Recap: ..." summary paragraph
  at the end of each round of your answer
- No matter which language is used during communication,
  write code/comments/summarization in English
- Use Python elegantly and wisely; don't write slop Python
- Use `uv` for Python dependency management, environment setup, and running checks
- Use only fully FOSS libraries;
  don't use libs like streamlit that comes with opt-out telemetry
- work on separate feat/ branches; make small and in-time commits
